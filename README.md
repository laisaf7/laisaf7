<h2>Sobre mim:</h2>
Sou a Laís e comecei a estudar desenvolvimento front-end em 2023. Estudo Análise e Desenvolvimento de Sistemas na FIAP com previsão de conclusão para Junho de 2027. Desenvolvedora de Software focada na criação de aplicações web e mobile modernas, escaláveis e de alto impacto social e de negócios. Transito entre o desenvolvimento de interfaces intuitivas no Frontend (React, TypeScript) e a construção de arquiteturas sólidas no Backend (Java, Spring Boot, SQL).
